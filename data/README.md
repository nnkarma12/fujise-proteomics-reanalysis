The analysis reads four supplementary files published by other groups. We
haven't included them here — download them from the publishers and drop them
into this folder, using the filenames below so the notebook finds them.

**`hobson_elife-70921-fig2-data5-v2.xlsx`**
Hobson et al. (2022) *eLife*, Figure 2—source data 5.
doi.org/10.7554/eLife.70921

**`pagetblanc_41467_2022_30776_MOESM1_TableS3.xlsx`**
Paget-Blanc et al. (2022) *Nature Communications*, Supplementary Table 3.
doi.org/10.1038/s41467-022-30776-9
This one is published as a PDF, so we converted it to a spreadsheet. No values
were changed.

**`asmerian_adz6836_table_s1.xlsx`** and **`asmerian_adz6836_table_s2.xlsx`**
Asmerian et al. (2026) *Science Advances*, Tables S1 and S2 — the striatal LP2
and P4 fractions respectively.
doi.org/10.1126/sciadv.adz6836
Note that Table S3 from the same paper covers whole brain rather than striatum,
and isn't used here.
